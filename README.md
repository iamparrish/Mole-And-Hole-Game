# 🐭 Mole and Hole Game

A fun, reflex-based browser game where players whack moles as they pop up from random holes. React fast — the moles disappear quickly, and every level gets faster!

## 🎮 About the Game

Moles randomly appear from holes scattered across the game board. Click or tap on a mole before it ducks back underground to score a point. With each passing level, the moles pop up and disappear faster, pushing your speed and accuracy to the limit.

Simple to pick up, tough to master — the perfect reflex trainer!

---

## ✨ Features

- Randomly generated mole positions for unpredictable gameplay
- Progressive difficulty — moles get faster with each level
- Score tracking to keep you competing against yourself
- Clean, responsive UI built with vanilla HTML, CSS, and JavaScript
- No installation or dependencies required — runs directly in the browser

---

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser. No frameworks or build tools required.

### Run Locally

```bash
git clone https://github.com/iamparrish/Mole-And-Hole-Game.git
cd Mole-And-Hole-Game
```

Open `index.html` in your browser — that's it!

## 🕹️ How to Play

1. Click **Start** to begin the game.
2. Watch the holes — moles will pop up randomly.
3. Click/tap a mole before it disappears to score a point.
4. Each level speeds up the moles. Survive as long as you can!
